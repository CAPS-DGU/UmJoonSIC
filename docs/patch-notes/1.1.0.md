# 엄준SIC 1.1.0 패치노트

2026.10.07

1.1.0 업데이트 내용을 안내해 드립니다.

## 주요 내용

- 영어 / 한국어 화면, 다크모드
- 환경 설정 창
- 장치 패널: 프로그램이 장치로 읽고 쓴 바이트를 실행 중에 확인
- 리스트파일 개편: 실행 중 리스트파일 ↔ 소스 ↔ 메모리 사이를 클릭으로 이동
- 자동 열 맞춤 개편
- 리눅스(x64) 지원

## 신규 기능

### 화면과 설정

- 영어와 한국어 화면을 지원합니다.
  - 처음 실행하면 운영체제 언어를 따릅니다.
  - 상태 표시줄, 보기 메뉴, 환경 설정에서 바꿀 수 있습니다.
- 다크모드가 추가되었습니다.
- 환경 설정 창이 추가되었습니다. (파일 > 환경 설정, Ctrl+,)
  - 언어, 테마, 실행 간격, 코드 글꼴 크기, 시뮬레이터 포트를 바꿀 수 있습니다.
  - 설정은 프로그램을 다시 시작해도 유지됩니다.
- 파일 목록, 실행 패널, 아래 패널의 크기를 경계를 끌어서 조절할 수 있습니다.
  - 경계를 두 번 클릭하면 기본 크기로 돌아갑니다.
  - 조절한 크기는 다시 시작해도 유지됩니다.

### 실행과 디버깅

- 장치 패널이 추가되었습니다.
  - 실행 중 프로그램이 RD, WD, TD로 주고받은 바이트를 장치별로 보여 줍니다.
  - 입력 장치는 다음에 읽을 바이트가 커서로 표시됩니다.
  - 파일에 연결되지 않은 장치에 쓴 바이트는 '버려짐'으로 표시됩니다.
  - 문자 / 16진 보기와 복사를 지원합니다.
- 리스트파일이 실행과 하나로 묶였습니다.
  - 실행하면 리스트파일 탭이 하나 열리고, 그 안의 작은 탭으로 파일을 바꿔 봅니다.
  - PC가 다른 파일로 넘어가면 리스트파일도 그 파일로 넘어갑니다.
  - 행을 두 번 클릭하면 해당 소스 줄로 이동합니다.
  - 피연산자의 기호를 클릭하면 그 기호를 정의한 행으로 이동합니다.
  - 편집기 오른쪽 클릭 메뉴에 '리스트파일에서 보기'가 추가되었습니다.
  - 상태 표시줄의 '일시 중지됨'을 클릭하면 PC가 가리키는 행으로 이동합니다.
  - 실행 중 메모리의 바이트를 두 번 클릭하면 그 주소의 행으로 이동합니다.
  - 열 제목이 위에 고정되고, 표 너비가 창에 맞춰 줄고 늘어납니다.
- 메모리에 '최근 저장 위치' 버튼이 추가되었습니다.
  - 가장 최근에 실행된 저장 명령어(STA, STX, STCH 등)가 값을 저장한 위치로 바로 이동합니다.
- 변수 탭이 개선되었습니다.
  - 값이 바뀐 변수는 행 전체가 강조됩니다.
  - 변수를 두 번 클릭하면 리스트파일(실행 중)이나 소스의 해당 위치로 이동하고, 메모리도 그 위치를 보여 줍니다.
  - 배열은 이름 뒤에 []가 붙습니다. (예: BUFFER[])
- 값이 바뀐 메모리, 변수, 장치 바이트가 잠깐 깜빡이고 다음 단계까지 표시됩니다.
- 실행 메뉴와 단축키가 추가되었습니다.
  - 실행·계속 F5, 일시 중지 F6, 한 단계 F10, 처음부터 다시 Ctrl+Shift+F5, 중지 Shift+F5
- 실행 간격을 도구 모음 목록에서 고를 수 있으며, 실행 중에도 바로 적용됩니다. (기본 250 ms)
- 프로젝트마다 SIC / SIC/XE 모드를 기억하고, 도구 모음에 현재 모드가 표시됩니다. (#113, #114)
- 사용자 지정 지연 시간이 저장되어 다시 시작해도 유지됩니다. (#119)

### 프로젝트와 파일

- 파일 트리의 맨 위에 프로젝트가 표시됩니다. 누르면 프로젝트 설정이 열립니다.
- 프로젝트 설정이 개편되었습니다.
  - 어셈블할 파일의 순서를 끌어서 바꿀 수 있습니다. 파일 트리에도 순서가 표시됩니다.
  - 장치 표에서 소스가 쓰는 장치와 연결된 파일을 함께 보고, 바로 연결할 수 있습니다.
  - 바꾼 내용은 저장 버튼 없이 바로 저장됩니다.
- 새 파일 창에서 '어셈블 파일에 추가', '장치에 연결'을 고를 수 있습니다.
- project.sic 파일을 더블 클릭하거나 연결 프로그램으로 열면 그 프로젝트가 열립니다. (#108)
- .asm 파일을 밖에서 열면 가까운 프로젝트를 찾아 함께 엽니다.
  - 프로젝트가 없으면 파일만 열어 편집할 수 있고, '여기에 프로젝트 만들기'로 프로젝트를 만들 수 있습니다.
- 탭을 끌어서 순서를 바꿀 수 있습니다. (#116)
  - Ctrl+PageDown / Ctrl+PageUp: 다음 / 이전 탭
  - Ctrl+Shift+PageDown / Ctrl+Shift+PageUp: 탭 위치 이동

### 편집기

- 자동 열 맞춤이 새로 만들어졌습니다.
  - 어셈블러가 읽는 방식대로 레이블, 명령어, 피연산자, 주석을 구분합니다. 1열에 명령어를 입력해도 레이블이 되지 않습니다.
  - Enter를 누르면 새 줄은 명령어 칸(10열)에서 시작합니다. 레이블을 입력하면 1열로 옮겨집니다.
  - Tab / Shift+Tab으로 칸 사이를 이동합니다.
  - 소문자로 입력한 명령어는 대문자로 바뀌고, 점(.)이 없는 주석에는 점이 붙습니다.
  - 교재처럼 줄 번호가 붙은 코드나, 통째로 들여 쓴 코드를 붙여 넣어도 칸에 맞게 정리됩니다.
- 문서 서식으로 파일 전체를 정리할 수 있습니다. (Shift+Alt+F, 리눅스는 Ctrl+Shift+I)

### 설치

- 리눅스(x64)를 지원합니다.
  - 릴리스의 `install-linux.sh`만 받아 실행하면 설치됩니다. 프로그램 본체(tar.gz)는 설치 스크립트가 받아 옵니다.
  - `UmJoonSIC-linux-x64-1.1.0.tar.gz`를 직접 받아 압축을 풀고 `install.sh`로 설치해도 결과는 같습니다.
  - Wayland, X11 데스크톱 환경을 지원합니다.
- 처음 실행할 때 Java와 시뮬레이터를 받는 진행 상황이 시작 화면 오른쪽 아래에 표시됩니다.

## 변경 및 개선

- 스플래시 창이 더 이상 다른 창 위에 항상 떠 있지 않습니다. (#117)
  - 작업 표시줄과 Alt+Tab에 표시되고, 끌어서 옮길 수 있습니다.
  - 시작이 끝나기 전에 스플래시를 닫으면 시작이 취소되고 프로그램이 종료됩니다. (#118)
- 실행 중 리스트파일 탭을 닫으면 실행을 멈출지 먼저 묻습니다. 리스트파일을 닫아 실행 흐름을 잃던 불편이 개선되었습니다. (#115)
- 프로그램이 종료(halt)되면 창을 띄우지 않고, 레지스터, 메모리, 변수, 리스트파일이 마지막 상태로 남습니다.
- 파일에 연결되지 않은 장치를 쓰는 프로그램을 실행하면 알려 줍니다. 버튼 한 번으로 새 파일을 만들어 연결하고 다시 시작할 수 있습니다.
- 출력만 하는 장치의 파일은 실행을 시작할 때 비워집니다. 이전 실행의 출력이 뒤에 남던 문제가 개선되었습니다.
- 수정한 탭이나 프로젝트를 닫을 때, 프로그램을 끝낼 때 저장 여부를 묻습니다.
- 오류 목록에서 오류를 누르면 해당 줄로 이동합니다. 파일을 열면 바로 문법을 검사합니다.
- 한국어 용어와 문구를 교재와 수업에서 쓰는 말로 정리했습니다. (리스트파일, 목적코드(OBJCODE) 등)
- 화면 배치를 정리했습니다. (막대 높이, 버튼 크기, 글꼴, 스크롤 막대, 대화상자)
  - 탭이 많아지면 탭 줄이 스크롤됩니다.
  - 긴 프로젝트·파일 이름은 말줄임(…)으로 표시되고, 마우스를 올리면 전체 이름이 보입니다.
- 정보 창에 실제 프로그램 버전이 표시됩니다.

## 버그 수정

- 중단점이 해당 줄을 실행한 뒤에 멈추던 현상이 수정되었습니다. 이제 실행하기 전에 멈춥니다. (#110)
- 계속 실행에 사용자 지정 지연 시간이 적용되지 않던 현상이 수정되었습니다. (#111)
- Ctrl+W를 누르면 프로그램이 종료되던 현상이 수정되었습니다. 이제 Ctrl+W는 현재 탭을 닫습니다. (#112)
- 인터넷에 연결되지 않은 상태에서 편집기가 열리지 않던 현상이 수정되었습니다.
- 다른 탭으로 갔다 돌아오면 저장하지 않은 편집 내용이 사라지던 현상이 수정되었습니다.
- 메모리 뷰어가 프로그램 영역 밖에 쓴 값을 갱신하지 않던 현상이 수정되었습니다.
- SIC/XE로 바꾸면 오류가 발생하던 현상이 수정되었습니다.
- 실행 버튼을 빠르게 두 번 누르면 리스트파일과 변수가 두 번 표시되던 현상이 수정되었습니다.
- 다시 실행하면 중단점이 사라지던 현상이 수정되었습니다.
- 리눅스에서 처음 실행할 때 Java를 받다가 멈추던 현상이 수정되었습니다.
- 인터넷 연결 없이 처음 실행하면 프로그램이 멈추던 현상이 수정되었습니다. 이제 원인을 알려 주고 종료합니다.
- 시뮬레이터가 준비되기 전에 프로젝트가 열리면 메모리가 ER로 채워지던 현상이 수정되었습니다.
- 새 프로젝트의 main.asm이 문법 오류 2개로 시작하던 현상이 수정되었습니다.
- 다른 프로젝트를 연 뒤 앞의 프로젝트를 다시 열면 무시되던 현상이 수정되었습니다.
- 같은 프로젝트가 두 번 불러와지던 현상이 수정되었습니다.
- 이름이 같은 두 폴더가 함께 펼쳐지던 현상이 수정되었습니다.
- 폴더를 선택하고 새 폴더를 만들면 엉뚱한 위치에 만들어지던 현상이 수정되었습니다.
- 프로젝트 폴더 이름으로 시작하는 다른 폴더(예: proj와 proj2)의 파일을 프로젝트 안의 파일로 보던 현상이 수정되었습니다.
- 장치 번호 0x0A 이상이 설정에서 다르게 표시되던 현상이 수정되었습니다.
- 읽을 수 없는 파일을 열면 빈 탭이 열려, 저장 시 파일이 비워질 수 있던 현상이 수정되었습니다.
- 메모리 뷰어 때문에 실행 패널 전체가 따로 스크롤되던 현상이 수정되었습니다.
- 10진수 모드에서 메모리의 마지막 열이 잘리던 현상이 수정되었습니다.
